How to Use EmailGuard AI

Step-by-step guide to analyze any suspicious email.

1

Get the .eml file from your email client

📧 Gmail

  1. Open the suspicious email
  2. Click the three dots menu ⋮ at the top right of the email
  3. Click "Download message"
  4. A .eml file is saved to your Downloads folder

📧 Outlook (Desktop)

  1. Open the suspicious email
  2. Click File → Save As
  3. Change file type to "Outlook Message Format (*.msg)" or "Text Only (*.txt)"
  4. Save and upload that file here

📧 Outlook Web / Office 365

  1. Open the suspicious email
  2. Click the three dots ⋯ menu
  3. Click "View message source"
  4. Select all the text (Ctrl+A) → copy → paste into a text file
  5. Save the file as email.eml

📧 Thunderbird

  1. Right-click the suspicious email in the list
  2. Click "Save As"
  3. Save as .eml format
2

Upload to EmailGuard AI

Go to the Analyze page.

Drag and drop your .eml file onto the upload area, or click to browse.

Click "Analyze Email" — you will see each analysis layer complete in real time.

3

Read your report

🚨

PHISHING

Do not click any links. Report to your IT team.

✅

LEGITIMATE

Email appears safe based on all analysis layers.

⚠️

NEEDS REVIEW

Uncertain — treat with caution, review manually.

4

Verify the blockchain anchor

Every report is automatically anchored on Ethereum Sepolia blockchain.

To verify a report was not tampered with:

  1. Click "View on IPFS" in your report
  2. Download the JSON file
  3. Compute its SHA-256 hash
  4. Compare it to the hash shown in the report (also on-chain)
  5. If they match — the report is forensically intact ✓
